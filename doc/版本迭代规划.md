## 二、v0.1.0 的用户可见交付

### 2.1 自由探索

用户能够从空棋盘开始，选格投沙，运行/暂停、单步观察连锁崩塌，等待稳定并保存实验。

- 固定四邻接、阈值 4、开放耗散边界；边角也使用阈值 4。
- 提供 33×33、65×65、129×129 三档，默认 65×65；本版预设基准和取消验收已通过，具体设备性能限制见测试报告。
- 鼠标/触摸离散点击投沙，键盘移动选格并 Enter/Space 投沙；投沙档位 1/10/100/1000 和受限合法整数输入。
- 空棋盘、中心堆沙、满 3 加一粒三类预设。
- 运行、暂停、同步波单步、可中止稳定化、速度控制；运行中输入有序处理，清空/重置时旧任务失效。
- 0/1/2/3 图例、选中格坐标/粒数、不稳定状态，以及总量、投入、流失和基础崩塌计数。

### 2.2 教学挑战

首版已交付 **6 个正式教学关**，以小棋盘为主。下列主题已落实为正式数据，最少步数依次 1、1、1、1、2、2；证明见关卡验证报告。

| 正式教学关 | 主题 | 玩家应理解的内容 |
| --- | --- | --- |
| L01 | 一粒沙的十字 | 稳定 3 粒加一粒触发四向崩塌 |
| L02 | 连锁反应 | 邻格获得一粒后也可能崩塌 |
| L03 | 角落流失 | 角格向外两粒消失，阈值不变 |
| L04 | 边缘传播 | 边格流失一粒，内部继续传播 |
| L05 | 落点选择 | 总量相同不代表图案相同，目标必须逐格匹配 |
| L06 | 组合投沙 | 在多个允许位置按有限预算组合投沙 |

已确认并实现的规则沿用需求：每步投一粒；只在稳定态行动；精确目标匹配；步数预算；重置与撤销；记录完成状态和个人最好步数。最后一步先判断通关，再判断预算耗尽。星级、排行榜和复杂奖励不进入首版。

每关必须有机器可重复的参考解与可达性验证；若展示“最少步数”，求解器必须逐层搜索并记录首次命中层。样例文件仍是 draft/unverified，不能未经证明进入正式列表。搜索超限的关卡不能带未经证明的最优性声明发布。

### 2.3 保存和离线

- 自由实验、本地关卡进度、设置采用独立键；刷新和重进能恢复，默认暂停。
- 浏览器 JSON 导出/导入，版本、规则、尺寸、粒数与统计严格校验；损坏文件不覆盖旧现场。
- 存储不可用或配额不足时显示明确提示，仍可在内存中继续并手动导出。
- 可双击构建产物离线运行；所有资源在本游戏目录下相对解析；同 origin 清空本游戏时其它数据保留。
- 本版先完成浏览器文件流程。宿主原生桥的注册与实际 Android 落盘，等待大厅项目提供能力和验收证据，不作为本窗口修改大厅的任务。

## 三、v0.1.0 的开发切片与顺序

以下是实现顺序，不是六个独立发行版本。每个切片先补针对性测试，再小步提交；提交完成后推送当前仓库。

| 顺序 | 对应计划 | 交付 | 提交原则 |
| --- | --- | --- | --- |
| 1 | B1 | 规则收敛、数值/大小上限、库选择，朴素参考引擎 | 先提交规则决策和参考用例 |
| 2 | B1 | 棋盘、同步波、合法队列稳定化、质量账本、取消编号 | grid / engine / cancellation 按行为拆分 |
| 3 | B2 | 版本化实验/进度格式、校验、事务导入与隔离键 | 存储独立于页面提交 |
| 4 | B2 | 自由探索的渲染、选格、投沙、播放、预设和统计 | 核心控件可端到端使用后再推进 |
| 5 | B3 | 挑战规则、数据校验、穷举工具、6 关教学数据 | 引擎 → 求解器 → 已证明关卡 → 页面集成 |
| 6 | B4 | 桌面/移动/键盘/触摸、离线/子路径、存档负例、性能实测 | 验证报告与状态同步；游戏端来源资料齐全 |

## 四、v0.1.0 验收门槛

1. **数学正确性**：U01–U13；参考引擎交叉验证、不同合法顺序终态一致、同步波语义、质量账本、边角耗散与非法输入全通过。
2. **挑战正确性**：U14–U20；非法操作不扣步、精确匹配、末步胜利优先、撤销一致、6 关可解性及所有最优性声明有证据。
3. **数据可靠性**：U21–U24；有效往返、损坏输入不污染现场、配额异常与跨项目哨兵保持。
4. **工程交付**：U25–U27；`node scripts/check.mjs`、`node --test`、`node scripts/build.mjs` 通过，正式关卡求解器加入本项目 CI 门禁，两次构建一致。
5. **真实交互**：游戏端 I01–I11/I14–I15 有真实浏览器证据，覆盖至少桌面 1280×900、手机 320×740、鼠标/键盘，以及移动触摸语义。移动模拟与真机证据分别注明，不能混称。
6. **性能可解释**：记录棋盘尺寸、粒数、设备/浏览器、稳定化耗时和任务中止响应；候选上限内控制始终可用，无数值溢出或长期冻结。未完成基准前不写 FPS 保证。

宿主端 I12–I13、H03/H05/H08 不属于本窗口实施门槛；H04/H06/H07 的游戏部分按上述数据/交互验证，宿主部分另由大厅项目完成。第一版可在独立浏览器交付，不等待大厅扩展。
