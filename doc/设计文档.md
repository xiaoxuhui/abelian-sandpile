## 1. 架构与库选择

经典 defer script 顺序加载，纯领域模块采用 UMD，同一份代码可在浏览器 file:// 离线运行或被 Node require 测试。无运行时第三方库、外网请求、Worker 或原生桥。

评估 [JS-Sandpile](https://github.com/huacayacauh/JS-Sandpile/) 和 [Sage sandpile](https://github.com/sagemath/sage/blob/develop/src/doc/en/thematic_tutorials/sandpile.rst)：前者是支持多种铺砌与任意图的完整应用，后者依赖 Sage 工具链。本版仅实现有限正方格规则，采用自包含引擎，配独立朴素参考实现、随机性质测试和关卡穷举；未复制这些项目源码。

```text
输入 → app 页面协调 → controller → sandpile / challenge
           ↓               ↓                ↓
       JSON 文件       可取消调度        状态、计数、队列
           ↕               ↓                ↓
       persistence ← 完整快照          renderer / Canvas
```

| 文件 | 实际职责 |
| --- | --- |
| domain/sandpile.js | 创建/校验、投沙、四邻规则、同步波、快速队列、物理账本 |
| domain/challenge.js | 关卡校验、合法动作、精确目标、撤销/快照/回放、广搜求解 |
| domain/levels.js | 从正式 JSON 同步的浏览器关卡数据 |
| storage/persistence.js | 存档 schema、严格临时校验、独立键、本地读写 |
| controller.js | 运行/暂停/单步/快速稳定化、排队、模式与通关记录 |
| renderer.js | DPR Canvas、颜色/数字、允许格/选格、命中换算 |
| app.js | DOM 控件、确认对话框、文件下载/导入、自动保存和页面生命周期 |

## 2. 数学状态与执行

规则标识 `square4-open-v1`：达到 4 粒可基础崩塌一次，四方向各给一粒，越过边界进入耗散汇。边格和角格阈值仍为 4。

行优先普通整数数组 `cells[y * width + x]`；状态保存 total、initialTotal、added、lost、topplings、逐格 odometer，以及当前/最近雪崩次数。必须满足 `total + lost = initialTotal + added`、odometer 总和等于 topplings。创建先校验尺寸，再分配数组，避免非法尺寸触发过量分配。

单步以轮初棋盘生成增量数组，每个不稳定格只崩塌一次，新触发留至下一轮。快速路径采用去重循环队列，处理某格 floor(n/4) 次合法崩塌，累计真实基础次数；与同步波和独立正序/逆序参考引擎终态、计数一致。

领域尺寸 1..129，UI 三档 33/65/129；单次 1..100000，本局初始＋累计投入≤1000000，统计≤10^12。输入在修改前原子校验；队列≤100 项，受理时预留累计预算。不稳定态的投入保存为纯数据，到稳定后按序执行。

控制器注入 schedule/cancel/clock 以测试。浏览器 cancel 包装 clearTimeout，保证正确调用上下文。每次暂停、重置、导入、模式切换更新 generation；旧帧检查编号后失效。快速帧计算预算 8ms，渲染/存储开销另计，未承诺固定 FPS；暂停后重新从不稳定格构造迭代器即可继续。

## 3. 挑战和证明

正式源 `data/challenges/levels.json` 六关，浏览器副本用 `scripts/sync-levels.mjs` 同步，CI 用 `--check` 防止漂移。`example.json` 保留为历史草案，不进入正式列表。

关卡为稳定初态和目标、允许位置、每步一粒、有限预算和参考动作序列。只有 playing 稳定态允许行动；非法位置/忙碌点击不投沙、不扣步。稳定后逐格精确匹配，最后一步优先判断通关，再判断预算失败。

撤销恢复动作之前的稳定棋盘、账本和步数；历史完成/最好步数独立保留。进行中挑战的存档回滚到未完成动作之前，恢复保持暂停，不恢复一半动画或扣除未完成步数。

求解器按深度广搜，每个合法动作后稳定化，按完整棋盘去重；首次目标层即最少步数。最多 100000 搜索节点，超限报错，不输出未经证明的最优值。生成工具先做独立引擎交叉验证与最少层证明，再输出 verified。验证工具重验所有正式数据，结果见[关卡验证报告](关卡验证报告.md)。

## 4. 存档合同与文件流程

已实现 `abelian-sandpile-save-v1`，包络 schemaVersion=1 / gameId=abelian-sandpile，包含 experiment（物理状态、纯数据队列、选格）、progress（关卡版本、最好步数）、settings（模式/速度/粒数/关卡 ID）和稳定 challenge（棋盘、账本、步数、撤销历史）。

键为 `abelian-sandpile.experiment.v1`、`.progress.v1`、`.settings.v1`。**experiment 键中的完整包络是恢复的唯一权威来源**；另两键是镜像，不跨键拼接混合版本。镜像写入失败提示未完整保存，内存现场仍可导出。清除只删除三个具体键。

导入≤2MiB，先校验 JSON、游戏/版本/规则、尺寸数组、所有数值、账本、队列预留、设置、关卡 ID/版本；挑战历史通过合法回放校验，进度通过预算内可达性校验。全部成功后提示确认，再一次替换内存现场并保存；取消或校验失败保留旧数据。验证不执行外来脚本，展示使用 textContent。

修改后 400ms 合并自动保存，pagehide 保存；页面隐藏暂停并保存。损坏已存包络不删除，默认空实验并明确提示。恢复默认暂停。浏览器 Blob/下载链接导出、file input 导入；没有声称支持 Android 原生落盘。

## 5. 界面、构建与接入边界

探索/挑战共享主棋盘，挑战显示目标、允许格、步数和结果。小棋盘显示数字；大棋盘提供坐标输入及键盘选择，减少触摸小格误差。颜色图例、焦点描边与文字状态协助操作。

Canvas 按容器/DPR 调整；窄屏单列，文件控件可换行，长统计数字可折行。真实 Chrome 已覆盖鼠标、键盘、模拟触摸、320px、旋转和大字体；未声称完成屏幕阅读器或 Android 真机验收。

Node 内置 API 构建固定 11 份运行资源（含 MIT LICENSE），生成版本/字节数/SHA-256 清单，排除开发工具、测试和文档；不写绝对路径或时间戳，同输入重复构建一致。

`game-hub.integration.json` 是 static 候选来源，登记真实仓库和游戏端资源/合同；revision、hostCompatibility、nativeBridge 仍为 null。它不是大厅锁文件或签名目录。游戏端根入口、file://、离线、子路径及同 origin 清空哨兵已测；大厅第五游戏注册、原生桥、合集构建和全游戏回归由大厅项目负责。

## 6. v0.1.1 循环投沙设计

在现有 controller 帧循环中加入临时 pouring 配置和 lastPour 时间，无第二套定时器。startPour 先验证模式/输入/预算，再取消旧任务并启动快速计算循环。每帧先处理手动队列，然后在稳定且间隔到期时投一次；是否继续运行同时取决于 pouring，稳定也继续等待下一次。间隔使用注入 clock，实际投入才更新时间，不追赶后台错过的轮次。

stop 清除 pouring 并递增 generation；所有既有取消入口共用该规则。输入预算不足在帧中报错、停止并通知页面。snapshot 仍为 save-v1，没有循环字段。UI 提供循环按钮、毫秒间隔和锁定坐标/粒数状态，活动时禁用循环配置；确认框先暂停，visibilitychange/pagehide 都停止。
