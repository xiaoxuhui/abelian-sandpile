# 阿贝尔沙滩安卓打包需求与测试用例

日期：2026-10-09；版本 v0.1.2；状态：规划。用户明确要求按 mini-app-harness 仓库技能现在发布 APK，覆盖原 v1.0 后再发布的安排。仅单游戏，不扩展大厅。

应用名阿贝尔沙滩，包名 com.xiaoxuhui.abeliansandpile，Android7.0+（minSdk24）、targetSdk34，versionName0.1.2、首包versionCode1。固定公开debug签名，Release标为预发行。完整离线，13份网页资源与网页构建完全同源；不申请网络及存储权限。
